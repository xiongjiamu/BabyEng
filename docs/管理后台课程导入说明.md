# 管理后台课程导入说明

管理员可在“设置 → 管理后台 → 课程内容”中选择 JSON 文件。文件可以是课程数组，也可以使用 `{ "items": [...] }` 包装；每次最多 500 条。同 ID 内容会更新，不同 ID 内容会新增。建议先以 `draft` 导入，人工核对后再改为 `published`；学习端只会收到已发布内容。

英语单词示例：

```json
[
  {
    "id": "word_apple",
    "subject": "english",
    "kind": "word",
    "category": "item_food",
    "en": "apple",
    "zh": "苹果",
    "aliases": ["苹果", "小苹果"],
    "phonetic": "/ˈæpəl/",
    "image_emoji": "🍎",
    "level": 1,
    "example_en": "This is an apple.",
    "example_zh": "这是一个苹果。",
    "review_status": "draft"
  }
]
```

英语情景短句使用 `kind: "sentence"`，`category` 填 `morning`、`meal`、`play`、`bedtime` 或 `outing`。

语文、数学示例：

```json
[
  {
    "id": "cn_water",
    "subject": "chinese",
    "kind": "activity",
    "category": "character",
    "title": "水",
    "prompt": "这是“水”字，找找家里的水杯。",
    "answer": "水",
    "image_emoji": "💧",
    "level": 1,
    "review_status": "draft"
  },
  {
    "id": "math_five",
    "subject": "math",
    "kind": "activity",
    "category": "counting",
    "title": "数字 5",
    "prompt": "数一数五根手指。",
    "answer": "5",
    "image_emoji": "✋",
    "level": 1,
    "review_status": "draft"
  }
]
```

课程 ID 只能包含字母、数字、横线和下划线，创建后不可修改。难度为 1～3。导入文件包含用户输入，后端会逐字段校验并通过 SQL 参数绑定保存。
