# 管理后台课程导入说明

管理员可在“设置 → 管理后台 → 课程内容”中选择 JSON 文件。文件可以是课程数组，也可以使用 `{ "items": [...] }` 包装；每次最多 500 条。同 ID 内容会更新，不同 ID 内容会新增。建议先以 `draft` 导入，人工核对后再改为 `published`；学习端只会收到已发布内容。

英语单词示例：

```json
[
  {
    "id": "word_apple",
    "subject": "english",
    "kind": "word",
    "category": "item_food",
    "en": "apple",
    "zh": "苹果",
    "aliases": ["苹果", "小苹果"],
    "phonetic": "/ˈæpəl/",
    "image_emoji": "🍎",
    "level": 1,
    "example_en": "This is an apple.",
    "example_zh": "这是一个苹果。",
    "review_status": "draft"
  }
]
```

英语情景短句使用 `kind: "sentence"`，`category` 填 `morning`、`meal`、`play`、`bedtime` 或 `outing`。

语言、数学亲子活动示例。`scene` 只能使用 `morning`、`meal`、`play`、`dressing`、`outing`、`bedtime`；发布状态必须完整填写材料、母亲话术、A/B 段动作、观察点和安全提醒：

```json
[
  {
    "id": "cn_big_small",
    "subject": "chinese",
    "kind": "activity",
    "category": "opposite",
    "title": "大和小",
    "prompt": "找两个大小不同的玩具比一比。",
    "answer": "大的玩具",
    "image_emoji": "🐘",
    "level": 1,
    "scene": "play",
    "materials": "一大一小两个安全玩具",
    "parent_script": "这个大，这个小。请把大的给妈妈。",
    "child_action_a": "看妈妈依次触摸两个玩具。",
    "child_action_b": "从两个玩具中指出或拿起大的。",
    "observe_for": "是否愿意同时看两个物品并注意差异。",
    "safety_note": "玩具应无小零件和尖角。",
    "material_tags": ["toys_blocks"],
    "interest_tags": ["animals", "building"],
    "review_status": "draft"
  },
  {
    "id": "math_five",
    "subject": "math",
    "kind": "activity",
    "category": "counting",
    "title": "两个",
    "prompt": "一只、两只，一共有两个。",
    "answer": "2",
    "image_emoji": "🧦",
    "level": 1,
    "scene": "dressing",
    "materials": "一双袜子",
    "parent_script": "一只、两只，一共有两个。",
    "child_action_a": "看妈妈逐个移动两只袜子。",
    "child_action_b": "把两只袜子逐个放进篮子。",
    "observe_for": "是否会一件一件移动并跟随数数节奏。",
    "safety_note": "不用带长绳或小装饰的物品。",
    "material_tags": ["clothing"],
    "interest_tags": ["movement"],
    "review_status": "draft"
  }
]
```

课程 ID 只能包含字母、数字、横线和下划线，创建后不可修改。难度为 1～3。导入文件包含用户输入，后端会逐字段校验并通过 SQL 参数绑定保存。

材料标签可使用 `household_objects`、`toys_blocks`、`food_tableware`、`clothing`、`movement_space`；兴趣标签可使用 `animals`、`music`、`vehicles`、`building`、`food`、`outdoors`、`movement`。已发布亲子活动至少需要一个材料标签，学习端据此过滤家庭当前没有条件开展的活动。
