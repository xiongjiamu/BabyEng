## 代码 Review（commit 64e0392）

**PRD 覆盖**：M1/M2/M3/M4/M5/M6/M8/M11 + 纯音频/引导/异常态/隐私同意/屏幕时间全部落地；**M7 亲子任务卡（PRD 7.2，V1 范围）未实现**；M9 母亲学习卡仅有字段级实现，Profile 页"每日汇总复习"未完整。

**P1（应修）**：
1. `matcher.rs::fuzzy` L2 编辑距离：同一目标多别名时 `seen.insert` 后更高 sim 的别名被跳过，记录非最高相似度，影响 ambiguous 二选一准确性。修：取最高 sim 而非首个达阈值。
2. `logic.rs::today_summary` streak 循环 N+1 查询：每轮查一次 child_daily，streak 长 = 查询多，首页加载性能隐患。修：一次 `SELECT day, frozen WHERE day <= today ORDER BY day DESC` 再内存算。
3. `Compare.vue::mark` 上传失败时 localStorage 缓存 pending 只存 metadata 不存 blob → 重试无法恢复音频，且违背 PRD 9.2「录音落盘即上传不堆积」。修：删除 pending 缓存，失败直接提示重录。

**P2（建议）**：
4. API 无鉴权 middleware（个人单家庭可接受，deploy/README 应明确「仅内网/HTTPS」避免公网裸跑）。
5. clippy 21 warnings（redundant closure / unused imports / never constructed structs）——风格类，不影响功能；models.rs 的 Recording/Progress 等用于反序列化，加 `#[allow(dead_code)]` 消噪。
6. `Compare.vue::mark` 第 229 行三元 `targetType === 'sentence' ? 'learn' : 'learn'` 两端相同，是冗余笔误，简化为 `'learn'`。
7. `normalize.rs` "杯子的"类所有格剥离仅对特定称谓词生效，通用"X的"靠 L2 兜底——可接受但不优雅。

**已知技术债（PRD 已标注待办，非 bug）**：TTS/ASR 模型未下载、iOS 真机实测未做、配图 emoji 占位、吉祥物 🐙 占位。
