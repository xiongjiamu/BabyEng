## 技术架构定稿（v0.3）

- 按用户要求重写第 9 章：后端语言从 Python/FastAPI 改为 **Rust（axum/actix-web）**，理由是性能、内存安全、单二进制便于 Docker、个人服务器占用低。
- 架构定调为「**Rust 业务后端 + 推理服务分离 + Docker 编排**」：Rust 跑 API/业务/数据库/配置/进度编排，AI 推理（TTS/ASR/LLM）独立服务化，Rust 调 HTTP/FFI。规避 Rust AI 生态弱项。
  - TTS：Piper ONNX，Rust 用 ort crate 直接加载或独立服务。
  - ASR：sherpa-onnx，FFI 或 HTTP；浏览器 webm/opus 需 ffmpeg 转 16k wav。
  - LLM：llama.cpp server / ollama（OpenAI 兼容 HTTP），Rust 按用户配置路由，不嵌后端，可热切换。
- 新增 **用户级模型配置**：每户可配自己的 LLM/TTS/ASR（local/openai/ollama provider），密钥加密存。新增 model_config、family_model_binding 等表（9.8 数据库设计）。
- 数据库：默认 SQLite（sqlx），多家庭上量可平迁 Postgres。补充 family/child/user_account 表。
- 新增 **9.9 Docker 部署**：docker-compose 编排 backend/web/tts/asr/llm/db，healthcheck + depends_on + profiles(mvp/full) + named volume 挂模型/音频/sqlite。
- 新增 **9.10 其他建议**：密钥 envelope 加密、音频转码、TTS hash 缓存、配置热更新、UTC 存本地时区查、推理熔断降级、备份、tracing 可观测。
- 9.7 硬件参考调整：Rust 占用低，新增 2 核 4G 无 LLM 档；走云端 API 的用户本地可不跑 LLM。
- 迭代技术行同步更新（MVP/V1/V2 改 Rust + Docker + 推理分离 + 模型配置）。
- 用户确认**可引入 Python**：推理服务（TTS/ASR/LLM）统一用 Python 实现（vLLM/llama-cpp-python/Coqui/sherpa-onnx Python 绑定），封装为 FastAPI 微服务暴露 HTTP，Rust 后端调。技术栈分工定型：Rust 管业务性能与并发，Python 管推理生态与迭代速度。已在 9.1/9.3/9.6/9.9 落地。
